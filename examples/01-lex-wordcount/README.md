# 01 · flex 로 만드는 wc(1)

lex 입력 파일의 가장 작은 완전한 예. 줄·단어·문자 수를 센다.

## 보는 것

- **세 부분 구조** — `정의부 %% 규칙부 %% 사용자 코드`
- **규칙 = 패턴 + 액션** — 패턴에 맞으면 액션이 실행된다
- `yytext`(매치된 문자열)와 `yyleng`(그 길이)
- 입력의 **모든 문자**가 어떤 규칙엔가 걸리도록 규칙을 배치하는 법
  (`{word}`, `\n`, `[ \t]` 셋이 입력 전체를 덮는다)

## 실행

```bash
make && make test
./wordcount < tests/basic.in
wc -lwc tests/basic.in      # 진짜 wc 와 비교해 보자
```
