# 04 · 시작 조건으로 정규 표현의 한계 넘기

`%x` 배타적 시작 조건을 써서 스캐너에 "모드"를 준다.

## 보는 것

- `%x` 와 `BEGIN(...)` 으로 상태 전환
- **중첩 블록 주석** — 정규언어가 아니므로 `depth` 카운터가 반드시 필요하다.
  이 변수를 쓰는 순간 스캐너는 순수 유한 오토마타를 벗어난다
- **문자열 리터럴** — 이스케이프를 *해석한 값*을 누적한다
  (정규 표현 하나로 매치만 하는 것과의 차이)
- `<<EOF>>` 규칙으로 "닫히지 않은 주석/문자열" 진단
- 시작 조건 안에서도 catch-all 이 필요하다는 것

## 실행

```bash
make && make test
./states < tests/nested.in     # 중첩 주석
./states < tests/strings.in    # 이스케이프 해석
./states < tests/unclosed.in   # EOF 진단
```
