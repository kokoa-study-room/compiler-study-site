# 05 · 재귀 하강 계산기

넌터미널 하나에 함수 하나. 교안 13장의 LL(1) 하향식 파싱을 손으로 쓴 것.

## 보는 것

- **넌터미널 = 함수** 라는 재귀 하강의 기본 대응
- 좌재귀를 제거하면 EBNF 반복 `{ }` 이 되고, 그것이 `while` 루프가 된다
- **좌결합을 유지하려면 값을 왼쪽으로 접어야 한다** —
  좌재귀 제거의 실질적 대가가 이 한 줄에 있다

  ```c
  left = new_binop(op, left, right);   /* ← 왼쪽으로 접는다 */
  ```
- **호출 스택이 곧 파싱 스택** (`-t` 로 눈에 보인다)
- 문맥을 아는 오류 메시지 — `[factor 를 파싱하는 중]`

## 실행

```bash
make && make test
./calc    < tests/basic.in
./calc -t < tests/trace.in      # 재귀 호출 추적
./calc    < tests/errors.in     # 오류 진단
```
