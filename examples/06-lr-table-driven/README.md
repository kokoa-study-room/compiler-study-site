# 06 · 표 구동 LR 파서

교안 14장에서 손으로 만든 SLR(1) 표를 그대로 C 배열로 옮긴 파서.
yacc 없이, 생성기 없이, 표와 20줄짜리 구동 루프만으로 동작한다.

## 보는 것

- **14장의 표 = 이 파일의 배열**. `ACTION[12][6]`, `GOTO[12][3]` 을
  교안의 표와 나란히 놓고 대조해 보자
- LR 구동 알고리즘의 전부 — 이동, 축약, GOTO, 수락
- **의미 값 스택**이 상태 스택과 나란히 움직인다.
  이것이 yacc 의 `$$`, `$1`, `$2` 의 정체다
- 축약 순서를 뒤집으면 **우측 유도**가 나온다
- 오류 시 "기대하는 토큰 목록"을 표의 행에서 그냥 읽어 낼 수 있다

## 실행

```bash
make && make test
./lrparse    < tests/basic.in
./lrparse -t < tests/trace.in     # 스택/입력/동작 추적
./lrparse    < tests/errors.in    # 오류 진단
```

`-t` 출력의 9번 행을 보자.

```
   9 | 0 E 1 + 6 T 9                | * 4 $          | 이동 s7
```

스택이 `E + T` 이고 입력이 `*` 다. 여기서 `E → E + T` 로 축약할 수도 있었지만
표가 **이동**을 지시한다. 곱셈이 먼저이기 때문이다.
연산자 우선순위가 표의 한 칸에 새겨져 있다.

## 05번 예제와 비교

같은 언어를 [05-recursive-descent](../05-recursive-descent)에서는
하향식으로 파싱한다. 두 방향의 차이를 나란히 보자.

| | 05 재귀 하강 (LL) | 06 표 구동 (LR) |
|---|---|---|
| 문법 | 좌재귀 제거 필요 | 좌재귀 그대로 |
| 결합성 | 액션 코드에서 왼쪽으로 접음 | 문법이 알아서 |
| 코드 | 문법이 그대로 보임 | 표를 봐야 함 |
| 오류 메시지 | 문맥을 안다 | 기대 토큰 목록 |
