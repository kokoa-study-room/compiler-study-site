# 시작하기 전에

이 교안은 **1학년 수준을 전제**로 쓰였다.
그래도 몇 가지는 알고 있어야 막히지 않는다.

이 문서는 **참조용**이다. 처음부터 다 읽을 필요는 없다.
본문을 읽다 막히면 여기로 돌아와 해당 항목만 보면 된다.

## 1. 프로그래밍

### 필수 — 이 정도는 알아야 한다

| 개념 | 왜 필요한가 | 어디서 나오는가 |
|---|---|---|
| 변수, 조건문, 반복문 | 모든 예제 | 전부 |
| **함수 호출과 반환** | 재귀 하강 파서의 핵심 | 13장 |
| **재귀** | 문법이 재귀적이므로 파서도 재귀적이다 | 10, 13장 |
| **배열** | 파싱 표가 곧 2차원 배열이다 | 5, 16장 |
| **스택** (LIFO) | 파서의 심장 | 10, 13~16장 |

**스택만은 확실히 하고 가자.**

```
push(x)   맨 위에 올린다
pop()     맨 위를 꺼낸다 (그것이 가장 최근에 올린 것)
top()     맨 위를 꺼내지 않고 들여다본다
```

"나중에 넣은 것이 먼저 나온다"(Last In, First Out).
[10장](/docs/parsing/context-free-grammar#103-푸시다운-오토마타)에서
**파서가 스택을 갖는 것이 이론적 필연**임을 보이고,
[13장](/docs/parsing/ll-parsing)부터는 스택이 계속 나온다.

### C 문법 — 예제 코드를 읽으려면

예제는 전부 C로 되어 있다. 다음을 알면 충분하다.

| 문법 | 예 | 어디서 |
|---|---|---|
| 포인터와 `*`, `&` | `char *s`, `*p` | 전부 |
| 문자열 = `char` 배열 + `\0` | `strcmp`, `strlen` | 전부 |
| 구조체 | `struct Node { ... }` | 5번 예제부터 |
| `typedef` | `typedef struct Node Node;` | 5번 예제부터 |
| `enum` | `enum { TK_NUM, TK_PLUS }` | 3번 예제부터 |
| 2차원 배열 | `int table[12][6]` | 3, 6번 예제 |
| 동적 할당 | `malloc`, `calloc`, `free` | 5번 예제부터 |
| **공용체(`union`)** | `union { int i; char *s; }` | 7번 예제 (yacc `%union`) |
| 가변 인자 | `va_list`, `vprintf` | 8번 예제 (`emit`) |

:::info[공용체(union)는 낯설 수 있다]
구조체는 멤버를 **나란히** 두지만, 공용체는 **같은 자리에 겹쳐** 둔다.

```c
struct S { int i; double d; };   /* 크기 = 4 + 8 = 12바이트 (정렬 무시) */
union  U { int i; double d; };   /* 크기 = max(4, 8) = 8바이트 */
```

공용체는 **한 번에 하나의 멤버만** 유효하다.
`u.i` 에 넣고 `u.d` 로 읽으면 쓰레기가 나온다.

yacc의 `%union` 이 정확히 이것이다.
파서의 값 스택에는 정수도, 문자열 포인터도, AST 노드 포인터도 들어가야 하는데
**한 칸에는 그중 하나만** 들어 있다.
어느 멤버가 유효한지는 `%token <멤버>` 선언이 알려 준다.

[18장](/docs/yacc/yacc-overview#-union--의미-값의-타입)에서
"`%type` 을 잘못 쓰면 조용히 깨진다"고 경고하는 이유가 이것이다.
:::

### 몰라도 되는 것

- 멀티스레드, 네트워크, GUI
- C++ 이나 다른 언어
- 어셈블리 (읽을 줄만 알면 좋지만 필수 아님)
- 컴퓨터 구조 (레지스터가 뭔지 정도면 충분)

## 2. 이산수학

겁먹을 필요 없다. 쓰는 것은 **집합과 함수 표기**가 거의 전부다.

### 집합

| 표기 | 읽는 법 | 뜻 |
|---|---|---|
| $\{a, b, c\}$ | 집합 | 원소가 $a, b, c$ |
| $x \in A$ | $x$ 는 $A$ 의 원소 | 소속 |
| $x \notin A$ | 아니다 | |
| $A \cup B$ | 합집합 | $A$ 또는 $B$ |
| $A \cap B$ | 교집합 | $A$ 이고 $B$ |
| $A - B$ | 차집합 | $A$ 이지만 $B$ 는 아님 |
| $A \subseteq B$ | 부분집합 | $A$ 의 모든 원소가 $B$ 에 있다 |
| $A \subsetneq B$ | **진**부분집합 | 부분집합이면서 같지는 않다 |
| $\emptyset$ | 공집합 | 원소가 하나도 없다 |
| $\lvert A \rvert$ | 크기(cardinality) | 원소 개수 |
| $A \times B$ | 곱집합 | 순서쌍 $(a, b)$ 전부 |
| $2^A$ | **멱집합(power set)** | $A$ 의 **모든 부분집합**의 집합 |

:::danger[$2^A$ 는 "2의 A제곱"이 아니다]
$2^A$ 는 **멱집합** — $A$ 의 모든 부분집합을 모은 집합이다.

$A = \{1, 2\}$ 이면
$$2^A = \{\ \emptyset,\ \{1\},\ \{2\},\ \{1,2\}\ \}$$
원소가 **4개**다.

$|A| = n$ 이면 $|2^A| = 2^n$ 이라서 이런 기호를 쓴다.
각 원소를 "넣는다/뺀다" 두 가지로 고르므로 $2^n$ 가지다.

[5장의 NFA 정의](/docs/regular/finite-automata#52-비결정적-유한-오토마타-nfa)에
$\delta : Q \times \Sigma \to 2^{Q}$ 가 나온다.
"전이 함수가 **상태의 집합**을 돌려준다"는 뜻이다.
DFA는 $\delta : Q \times \Sigma \to Q$ — 상태 **하나**를 돌려준다.
이 한 글자 차이가 결정성/비결정성의 전부다.
:::

### 함수와 관계

| 표기 | 뜻 |
|---|---|
| $f : A \to B$ | $A$ 의 각 원소를 $B$ 의 원소 하나로 보내는 함수 |
| $f(a) = b$ | $a$ 를 $b$ 로 보낸다 |
| $A \times B \to C$ | 인자를 **둘** 받는 함수 (첫째는 $A$, 둘째는 $B$) |

$\delta : Q \times \Sigma \to Q$ 는
"상태 하나와 기호 하나를 받아 상태 하나를 돌려주는 함수"다.
C로 쓰면 `int delta(int state, char c)` 다.

### 증명 기법 셋

**① 귀류법 (proof by contradiction)**

"$P$ 가 참이다"를 보이려고 **"$P$ 가 거짓이다"라고 가정**한 뒤
모순을 이끌어낸다. 모순이 나오면 가정이 틀린 것이므로 $P$ 가 참이다.

[3장의 펌핑 보조정리 증명](/docs/regular/regular-languages#proof-anbn)이
이 방식이다.
"$\{a^nb^n\}$ 이 정규라고 가정" → 모순 → "정규가 아니다".

**② 비둘기집 원리 (pigeonhole principle)**

> 비둘기 $n+1$ 마리를 비둘기집 $n$ 개에 넣으면,
> **적어도 한 집에는 두 마리 이상**이 들어간다.

당연해 보이지만 강력하다.

[3장](/docs/regular/regular-languages#펌핑-보조정리)에서:
> 상태가 $p$ 개인 DFA로 길이 $p$ 이상인 스트링을 읽으면
> 상태를 $p+1$ 번 이상 방문한다.
> 따라서 **같은 상태를 두 번 지난다.**

비둘기 = 방문 횟수, 비둘기집 = 상태. 그래서 반드시 **고리(loop)** 가 있다.

[10장의 CFL 펌핑 보조정리](/docs/parsing/context-free-grammar#104-cfg의-펌핑-보조정리)도
같은 논법이다 — 넌터미널이 유한 개이므로 깊은 경로에는 같은 넌터미널이 두 번 나온다.

**③ 귀납적 정의와 구조적 귀납법**

"기본 규칙 몇 개 + 조립 규칙"으로 무한한 대상을 정의하는 방식이다.

```
정규집합의 정의:
  기본:  ∅, {ε}, {a} 는 정규집합
  귀납:  R, S 가 정규집합이면 R∪S, RS, R* 도 정규집합
  폐쇄:  위 규칙을 유한 번 적용한 것만 정규집합
```

[3장](/docs/regular/regular-languages#31-정규집합의-정의)의 정규집합,
[4장](/docs/regular/regular-expressions#41-형식적-정의)의 정규 표현이 이렇게 정의된다.

이렇게 정의된 대상에 대한 증명은 **같은 구조를 따라간다** —
기본에 대해 보이고, 조립 규칙마다 "부분에 대해 성립하면 전체에도 성립"을 보인다.

### 알고리즘 표기

| 표기 | 뜻 | 예 |
|---|---|---|
| $O(n)$ | 입력 크기에 **선형** | DFA로 스트링 인식 |
| $O(n^2)$, $O(n^3)$ | 제곱, 세제곱 | CYK 파싱은 $O(n^3)$ |
| $O(2^n)$ | 지수 — **실용적이지 않다** | NFA→DFA 최악의 경우 |
| $O(1)$ | 상수 — 입력 크기와 무관 | 배열 접근 |

정확한 정의를 몰라도 된다.
**"입력이 두 배가 되면 시간이 얼마나 늘어나는가"** 정도로 읽으면 충분하다.

- $O(n)$ — 두 배
- $O(n^2)$ — 네 배
- $O(2^n)$ — **감당 불가**

## 3. 그래프와 트리

파스 트리, 상태 전이도, 의존 그래프가 계속 나온다.

| 용어 | 뜻 |
|---|---|
| 노드(정점) | 그림의 동그라미 |
| 간선 | 노드를 잇는 선 |
| 유향 그래프 | 간선에 방향이 있다 (화살표) |
| 경로 | 간선을 따라간 노드의 나열 |
| 사이클 | 출발점으로 돌아오는 경로 |
| 트리 | 사이클이 없고, 루트에서 모든 노드로 가는 경로가 유일한 그래프 |
| 루트 / 잎 | 맨 위 / 자식이 없는 노드 |
| 부모 / 자식 / 형제 | 트리의 관계 |

### 순회 순서 — 이건 꼭 알아야 한다

```
      A
     / \
    B   C
   / \
  D   E
```

| 순회 | 순서 | 규칙 |
|---|---|---|
| **전위(preorder)** | A B D E C | 부모 → 자식들 |
| **중위(inorder)** | D B E A C | 왼쪽 → 부모 → 오른쪽 |
| **후위(postorder)** | D E B C A | **자식들 → 부모** |

:::info[후위 순회가 이 교안의 핵심이다]
[17장](/docs/parsing/syntax-directed-translation#173-sdd와-주석-달린-파스-트리)과
[19장](/docs/yacc/yacc-grammar-and-actions#191-액션이-실행되는-시점)에서
"LR 파서의 액션 실행 순서 = 후위 순회"라는 사실이 반복해서 나온다.

**자식이 전부 처리된 뒤에 부모가 처리된다.**
그래서 자식의 값으로 부모를 계산할 수 있고(합성 속성),
피연산자의 코드가 항상 먼저 나온다(코드 생성).
:::

### 위상 정렬 (topological sort)

유향 그래프에서 "$A$ 가 $B$ 보다 먼저"라는 제약을 전부 만족하는 순서를 찾는 것.

**사이클이 있으면 불가능하다** — $A$ 가 $B$ 보다 먼저이고
$B$ 가 $A$ 보다 먼저일 수는 없기 때문이다.

[17장의 의존 그래프](/docs/parsing/syntax-directed-translation#174-의존-그래프)에서
속성 계산 순서를 정할 때 나온다.

## 5. 자주 헷갈리는 표기 미리 보기

본문에서 처음 만나면 당황할 수 있는 것들이다.
지금 외울 필요는 없고, "이런 게 나오는구나" 정도만.

| 표기 | 읽는 법 | 어디서 |
|---|---|---|
| $\varepsilon$ | 엡실론 — **빈 문자열** (길이 0) | 2장 |
| $\Sigma$ | 시그마 — **알파벳**(기호의 집합) | 2장 |
| $\Sigma^*$ | 시그마 스타 — $\Sigma$ 로 만들 수 있는 **모든** 문자열 | 2장 |
| $A \to \alpha$ | $A$ 를 $\alpha$ 로 바꿔 쓸 수 있다 (**생성 규칙**) | 2장 |
| $\alpha, \beta, \gamma$ | 알파, 베타, 감마 — **기호들의 나열** | 2장 |
| $\Rightarrow$ | 한 번의 **유도** | 2장 |
| $\Rightarrow^*$ | 0번 이상의 유도 | 2장 |
| $\delta$ | 델타 — **전이 함수** | 5장 |
| $2^Q$ | $Q$ 의 **멱집합** | 5장 |
| $A \to \alpha \cdot \beta$ | 점이 찍힌 **LR(0) 항목** | 15장 |
| $\lessdot\ \doteq\ \gtrdot$ | **우선 관계** (부등호가 아니다) | 14장 |
| $X.a$ | 심볼 $X$ 의 **속성** $a$ | 17장 |

전체 목록은 [용어 사전](/docs/reference/glossary)에 있다.
